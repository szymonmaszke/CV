# Security

Report any security vulnerabilities you find according to these guidelines.

## General

- Please adhere to [Code of Conduct](./CODE_OF_CONDUCT.md) at all times.

## Reporting a vulnerability

- If you discover a vulnerability, report it directly to the code maintainers,
  __preferably using GitHub's
  [Private Vulnerability Reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)__.
- If you cannot find a way to report it, or have received no response after
  repeated attempts, __[contact the owner directly](mailto:szymon@maszke.co).__

Thank you.
